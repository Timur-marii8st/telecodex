# Telegram Local — инструкция

Локальный MCP-коннектор личного аккаунта Telegram для Codex. Поддерживает QR-вход,
чтение доступных аккаунту облачных чатов, поиск, отправку сообщений и файлов.
Это самостоятельная оболочка над `chigwell/telegram-mcp`, а не официальный
плагин Telegram или OpenAI.

## Установка

Нужны Linux/macOS, Python 3.11+ с venv/pip, Git и собственные `api_id`/`api_hash`
из <https://my.telegram.org/apps>. Для автоматической регистрации нужен `codex`
в PATH. Windows в этой версии не поддерживается; можно использовать Linux/WSL.

В корне скачанного проекта:

```sh
./setup.sh
./run.sh login
./run.sh register-codex
./install-skill.sh
```

Если нужен определённый Python: `PYTHON=python3.12 ./setup.sh`.
Введите ключи в локальном терминале, отсканируйте QR через Telegram → Настройки →
Устройства → Подключить устройство. Пароль 2FA тоже вводится локально.
Запасной вход: `./run.sh login --phone`. Перезапустите Codex после регистрации.
Скилл необязателен и дополняет MCP-инструменты инструкциями для агента.

## Если соединение зависает

Прокси по умолчанию выключен. Для v2rayN или другого локального SOCKS5:

```sh
./run.sh proxy --type socks5 --host 127.0.0.1 --port 10808
./run.sh doctor --network
./run.sh login
```

Укажите действительный адрес и порт своего прокси. Настройка применяется и к
входу, и к MCP. Приложение прокси должно работать. Отключить: `./run.sh proxy --off`.

## Проверка и режимы

```sh
./run.sh doctor
./run.sh status
./run.sh check-mcp
./run.sh mode read-only
./run.sh mode messaging
./run.sh mode full
```

`doctor` проверяет настройки; с `--network` — доступность TCP-маршрута.
`status` проверяет реальную авторизацию и читает один диалог. `check-mcp`
проверяет протокол MCP, список инструментов, аккаунт и чтение «Избранного».
Проверки ничего не отправляют. Для `status`/`check-mcp` остановите активное
MCP-подключение: одну сессию использует один процесс.

Режим по умолчанию — `messaging`: чтение, отправка, ответы и файлы. `full`
добавляет административные и разрушительные операции. После смены режима или
прокси переподключите MCP. Секретные чаты недоступны.

## Личные данные и Git

Скрипты проекта хранят данные в игнорируемой папке `private/`. В ней находятся
ключи, сессия, настройки и файлы Telegram. Права каталога — 0700, ключей и
сессии — 0600; шифрование отдельно не реализовано. Чтобы выбрать другой каталог:
задайте `TELEGRAM_LOCAL_HOME`. Не публикуйте `private/`, QR или логи с перепиской.
